# ⚡ Lembar Panduan Cepat (Quick Start Cheatsheet)
### Santri Analytics — Setup Kilat 10 Menit untuk Admin Pondok

---

```
  [ 1. SALIN FILE ]        [ 2. BUKA WIZARD ]       [ 3. UPLOAD JADWAL ]       [ 4. GO-LIVE ]
 Salin Spreadsheet &      Login (mudir/admin123)     Upload Excel Jadwal      Bagikan link ke
 Template Raport ke       -> Buka Menu Setup         KBM & pasangkan akun     Ustadz & Wali Santri
```

---

## 7 Langkah Wizard Setup (Cukup Sekali Dilakukan):

| Langkah | Nama Langkah | Tindakan yang Perlu Dilakukan | Target Hasil |
| :---: | :--- | :--- | :--- |
| **1** | **Profil & Database** | Masukkan Nama Pondok, Logo, dan tempel **Link Spreadsheet** salinan pondok Anda. Klik *Simpan Profil & Hubungkan*. | Database resmi pondok terhubung seketika. |
| **2** | **Paket Modul** | Biarkan Mode Penguncian pada opsi `Off`. Centang seluruh fitur yang ingin digunakan. | Modul Tahfidz, Nilai, Absensi, Perilaku aktif. |
| **3** | **Data Santri** | Unggah file data santri (CSV/Excel). Klik *Preview* lalu *Proses Import*. Klik *Pasangkan Wali ↔ Santri Asli*. | Santri terbaca & akun Wali otomatis tertaut. |
| **4** | **Jadwal KBM** | Klik *Pilih File Jadwal*, pilih file jadwal mingguan (.xlsx / .csv). Klik *Terapkan Jadwal*. | Ratusan jadwal tersimpan & akun Ustadz otomatis dibuat. |
| **5** | **Akademik** | Klik tombol hijau *Siapkan Periode & Item Ujian Otomatis (1x Klik)*. | Periode 2026/2027 aktif & item ujian raport siap. |
| **6** | **Akun Demo** | Simpan minimal 1 akun demo untuk uji coba pameran tanpa mengotori data asli. | Login akun demo aktif. |
| **7** | **Cek Kesiapan** | Jika ada kotak kuning, klik *⚡ Lengkapi Otomatis yang Kurang*, lalu klik *Selesaikan Setup*. | Status berubah menjadi: **100% Siap Pakai**. |

---

## 📱 Format Akun & Akses Pengguna:

* **Pimpinan Pondok / Mudir**:
  * Akses: Seluruh data, grafik dashboard rekapitulasi, persetujuan raport, dan kontrol sistem.
  * Login default: `mudir` / `admin123`
* **Dewan Guru / Ustadz**:
  * Akses: Input absensi KBM, setoran tahfidz juz/surat, catatan adab/perilaku, dan pengisian nilai raport.
  * Format login: Akun yang terdaftar otomatis saat upload jadwal (Kode: `T001`, `T002`, dst).
* **Wali Santri**:
  * Akses: Hanya memantau data perkembangan anaknya (kehadiran, hafalan, prestasi/pelanggaran, dan nilai raport).
  * Format login: Nomor WhatsApp Wali yang terdaftar atau NIS santri.

---

## 💡 3 Tips Penting:
1. **Ganti Password Admin**: Setelah setup selesai, segera buka menu *Ubah Password* di pojok kanan atas untuk mengganti password `admin123` demi keamanan.
2. **Kerapian Excel Jadwal**: Pastikan baris jadwal di Excel mencantumkan nama guru dan kelas secara konsisten agar akun Ustadz terbentuk rapi.
3. **Backup Otomatis**: Data Anda berada di Google Drive pondok Anda sendiri; Anda bisa mengunduh (*Download as Excel*) Spreadsheet database Anda kapan saja untuk backup lokal.
