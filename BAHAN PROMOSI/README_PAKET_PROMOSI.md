## 🔄 ALUR SISTEM PENJUALAN ONLINE (CUSTOMER JOURNEY)

Berikut adalah alur lengkap proses penjualan dari awal hingga pembeli puas:

```
  [ 1. IKLAN / KONTEN ]
  Calon pembeli melihat Iklan FB/IG, Reels, atau Broadcast WA
  (Gunakan berkas di folder 02_MATERI_PROMOSI_DAN_IKLAN)
            │
            ▼
  [ 2. LANDING PAGE / CHAT WA ]
  Calon pembeli membaca Landing Page atau menghubungi WA Anda
  (Gunakan berkas 01_COPYWRITING_LANDING_PAGE atau 03_IKLAN_WHATSAPP)
            │
            ▼
  [ 3. DEMO APLIKASI ]
  Anda memberikan link demo interaktif Staging & memandu presentasi
  (Gunakan berkas 05_PANDUAN_DEMO_DAN_PITCHING_SALES)
            │
            ▼
  [ 4. TRANSAKSI / PEMBAYARAN ]
  Calon pembeli memilih paket (Standar / Pro) dan mentransfer pembayaran
  (Gunakan script penutupan di 03_IKLAN_WHATSAPP)
            │
            ▼
  [ 5. PENGIRIMAN PRODUK OTOMATIS ]
  Email otomatis terkirim ke pembeli berisi link akses & master database
  (Kirimkan berkas 01_EMAIL_PENGIRIMAN_DAN_AKSES_PEMBELI)
            │
            ▼
  [ 6. SETUP MANDIRI / DIBANTU ]
  Pembeli mengikuti tutorial setup bergambar dari A sampai Z
  (Pembeli membaca berkas 02_PANDUAN_SETUP_MANUAL_LENGKAP & 03_QUICK_START)
            │
            ▼
  [ 7. GO-LIVE PESANTREN ]
  Pondok resmi memakai aplikasi & menyebarkan akun ke Ustadz & Wali
  (Pembeli memakai berkas 04_TEMPLATE_BROADCAST_WALI_DAN_GURU)
```

4. [ ] **Atur Email Pengiriman**: Masukkan teks di `01_EMAIL_PENGIRIMAN_DAN_AKSES_PEMBELI.md` ke email checkout platform Anda (atau simpan di draft Gmail/WA).
